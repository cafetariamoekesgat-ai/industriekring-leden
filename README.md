# Industriekring Ter Apel: pagina's voor leden

Statische pagina's (GitHub Pages) voor aanmelden voor bijeenkomsten, lid worden, de jaarplanning in je agenda en het beheerscherm van het bestuur.
De gegevens staan in Supabase en zijn afgeschermd; in deze repository staan geen persoonsgegevens of geheime sleutels.
De publishable key in `assets/config.js` is bedoeld om openbaar te zijn.
